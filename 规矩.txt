**[ID: NAME_RULES]**

**[DESCRIPTION: 一个关于修仙世界角色称谓的、高级动态规则集。此版本包含核心的“动态辈分”逻辑，并详尽规定了不同阵营、情感状态及道号的使用规则。]**

**[1.0_核心逻辑与判定流程 (Core Logic & Decision Flow)]**

*   `[LOGIC_1: 上下文判定 (Context Determination)]` -> **[RULE: 必须首先判定交互场景：“宗门内部”、“宗门之间”、“通用场景（散修/坊市）”。这是选择后续逻辑分支的基础。]**

*   `[LOGIC_2: 宗门内部动态辈分逻辑 (Sect-Internal Dynamic Seniority Logic)]` -> **[RULE: 此为宗门内部的最高优先级规则。判定时，必须检查称呼对象的修为（C）是否等于或超过了称呼者（A）的直系师父（B）。]**
    *   **[CONDITION_A: 如果 C 的修为 ≥ B 的修为，即使 C 入门更晚，A 也必须尊称 C 为“师叔”或“师伯”。]**
    *   **[CONDITION_B: 如果 C 的修为远超 B（例如跨越一个大境界），A 甚至可能需要尊称 C 为“师祖”。]**

*   `[LOGIC_3: 宗门内部标准辈分逻辑 (Sect-Internal Standard Seniority Logic)]` -> **[RULE: 仅当 `LOGIC_2` 的条件不满足时，才启用此规则。此时，称谓严格由师承关系决定，与修为无关。]**

*   `[LOGIC_4: 宗门外部与通用逻辑 (External & General Logic)]` -> **[RULE: 在宗门外部，**“相对修为差距”**是唯一准则。称谓由双方实力高低决定。]**

*   `[LOGIC_5: 道号使用规则 (Rule for Using Daoist Names)]` ->
    *   **[RULE_A: 首次见面或正式场合，必须使用“姓氏/道号 + 尊称/职务”（如：“见过李真人”、“拜见清月长老”）。]**
    *   **[RULE_B: 关系亲近的同辈之间，可省略尊称，直接称呼“XX兄/道友/仙子”（如：“清月道友，别来无恙”）。]**
    *   **[RULE_C: 提及不在场的强者时，使用其威震天下的名号（如：“那位传说中的‘血河老祖’...”）。]**
    *   **[RULE_D: 敌对或轻蔑时，可直呼其名或使用侮辱性绰号（如：“韩老魔，纳命来！”）。]**

*   `[LOGIC_6: 阵营风格差异 (Faction Style Differences)]` ->
    *   **[STYLE_A: 正道修士]** -> `[倾向于使用“道友”、“前辈”、“贫道”等较为谦和、礼貌的词汇。]`
    *   **[STYLE_B: 魔道/邪修]** -> `[倾向于使用更具威压和自我中心的词汇，如“本座”、“本尊”、“老祖”，并更频繁地使用蔑称。]`

*   `[LOGIC_7: 身份覆盖 (Position Override)]` -> **[RULE: 在任何场景下，对方的最高职务身份（掌门、家主）在正式场合具有最高称谓优先级。]**

**[2.0_称谓词典 (Glossary of Address)]**

*   **[CATEGORY: 通用中立称谓 (General & Neutral)]**
    *   `[TERM: 前辈]` -> `[CONDITION: 对方修为显著高于自己（通用场景）。]`
    *   `[TERM: 道友]` -> `[CONDITION: 双方修为相仿、不明或差距不大时的默认称呼，也可以出现在高境界对低境界时不愿意暴露实力的情况下。]`
    *   `[TERM: 小友]` -> `[CONDITION: 自身修为显著高于对方时的客气称呼。]`

*   **[CATEGORY: 宗门体系称谓 (Sect System)]**
    *   `[TERM: 师祖/老祖]` -> `[CONDITION: 对方是师父的师父辈，或其修为远超自己师父（见 LOGIC_2）。]`
    *   `[TERM: 师叔/师伯]` -> `[CONDITION: 对方是师父的同辈，或其修为等于/超过自己师父（见 LOGIC_2）。]`
    *   `[TERM: 师兄/师姐]` -> `[CONDITION: 标准辈分下的同门前辈。]`
    *   `[TERM: 师父/师尊]` -> `[CONDITION: 自己的直系授业恩师。]`

*   **[CATEGORY: 敌对与轻蔑称谓 (Hostile & Disdainful)]**
    *   `[TERM: 老贼 / 妖妇 / 匹夫]` -> `[CONDITION: 双方敌对，用于辱骂同辈或稍强于自己的对手。]`
    *   `[TERM: 妖人 / 魔头]` -> `[CONDITION: 对邪派修士的通用蔑称，或对其首领的称呼。]`
    *   `[TERM: 小辈 / 小儿]` -> `[CONDITION: 高阶修士对低阶修士的轻视称呼，充满不屑。]`
    *   `[TERM: 蝼蚁 / 毛虫]` -> `[CONDITION: 实力差距悬殊时，强者对弱者的极致蔑视。]`

*   **[CATEGORY: 特殊身份与场合 (Special Positions & Occasions)]**
    *   `[TERM: 掌门/宗主/家主/陛下/大王]` -> `[CONDITION: 一个势力的最高领导者。]`
    *   `[TERM: 真人/真君/老祖/仙子]` -> `[CONDITION: 对外界公认的、拥有崇高地位和强大实力的修士的尊称，是一种“江湖地位”的体现。]`
    *   `[TERM: 大天尊/大帝/仙帝/仙尊/道祖]` -> `[CONDITION: 对整个世界观里也是最强大的那批道尊、道祖的尊称。]`
    *   `[TERM: 贵宗/敝宗]` -> `[CONDITION: 宗门之间交流时对宗门的敬称与谦称。]`

*   **[CATEGORY: 自称 (Self-Address)]**
    *   `[TERM: 晚辈/在下]` -> `[CONDITION: 谦称，面对长辈或强者时使用。]`
    *   `[TERM: 贫道]` -> `[CONDITION: 正道修士的通用谦称。]`
    *   `[TERM: 本座/本尊]` -> `[CONDITION: 威严自称，高位者或魔道枭雄常用。]`
    *   `[TERM: 老夫/老身]` -> `[CONDITION: 年长修士的通用自称。]`

*   **[LOGIC_ENFORCEMENT: 必须严格遵循 `1.0_核心逻辑与判定流程`。在宗门内部场景，必须优先应用 `LOGIC_2` 的动态辈分规则进行判断。]**
